تطبيق آلة حاسبة بسيط لنظام Android باستخدام Kotlin.

يسمح للمستخدم بإجراء العمليات الحسابية الأساسية، مع دعم الأرقام العشرية والنسب المئوية، وعرض المدخلات والنتائج من خلال واجهة بسيطة.

الميزات

- إدخال الأرقام والعمليات الحسابية الأساسية
- الجمع والطرح والضرب والقسمة
- دعم الأرقام العشرية
- دعم النسب المئوية
- حذف آخر إدخال
- مسح كامل الإدخال والنتيجة
- تقييم التعبيرات الحسابية
- تحديث حجم النص تلقائيًا عند الإدخال والنتيجة
- عرض النتائج للحسابات الصحيحة والعشرية

</div><div dir="ltr" align="left">Tech Stack

Technology| Usage

</div><div dir="rtl" align="right">طريقة الاستخدام

1. افتح التطبيق.
2. أدخل الأرقام والعمليات الحسابية باستخدام الأزرار.
3. استخدم النقطة العشرية عند الحاجة.
4. استخدم النسبة المئوية للحسابات التي تتطلبها.
5. اضغط على زر الحساب لعرض النتيجة.
6. يمكن حذف آخر إدخال أو مسح العملية بالكامل.

</div><div dir="ltr" align="left">Architecture

The application uses a simple Android UI structure with the main calculator logic handled by the application activity.

ConstraintLayout is used to organize the calculator interface, while exp4j is used to evaluate mathematical expressions.

</div><div dir="ltr" align="left">Getting Started

Requirements

- Android Studio
- Android SDK
- Kotlin

Setup

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync the project with Gradle.
4. Build and run the application.
