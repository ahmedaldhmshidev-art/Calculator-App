Calculator App
وصف المشروع:
تطبيق آلة حاسبة بسيط للأندرويد باستخدام Kotlin وConstraintLayout.
يمكن للمستخدم إجراء العمليات الحسابية الأساسية مثل الجمع، الطرح، الضرب، القسمة، النسبة المئوية، والنقاط العشرية.
يعتمد المشروع على واجهة مستخدم منظمة مع TextView لعرض المدخلات والنتائج، وأزرار تفاعلية لإدخال الأرقام والعمليات.

المميزات:
إدخال الأرقام والعمليات الحسابية الأساسية.
دعم النقاط العشرية والنسب المئوية.
حذف آخر رقم أو مسح كامل الشاشة.
تحديث حجم النصوص تلقائيًا عند الإدخال والنتيجة.
عرض النتائج بشكل صحيح عند الحسابات العشرية والكاملة.

:التقنيات المستخدمة
لغة البرمجة: Kotlin
ConstraintLayout لتصميم واجهة المستخدم.
استخدام ExpressionBuilder من مكتبة exp4j لتقييم التعبيرات الحسابية.
TextView لعرض المدخلات والنتائج.
AppCompatButton وImageView للأزرار.

:بنية المشروع
MainActivity.kt → النشاط الرئيسي للتطبيق، يحتوي على جميع الدوال لإدارة الأزرار، العمليات الحسابية، وتنسيق النصوص.
activity_main.xml → تصميم واجهة المستخدم باستخدام ConstraintLayout.

ملاحظات:
المشروع موجه لتعلم كيفية بناء آلة حاسبة متكاملة على أندرويد مع التعامل مع الأحداث النصية وتغيير حجم النصوص.
يمكن تطوير المشروع لاحقًا بإضافة وظائف متقدمة مثل العمليات العلمية أو حفظ التاريخ.
